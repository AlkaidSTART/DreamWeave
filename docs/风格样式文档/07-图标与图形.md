# 07 - 图标与图形

## 7.1 图标风格

采用 **Lucide Icons** 线性图标库，原因：

- 线条干净、统一 1.5px stroke
- 与 Geist / Satoshi 字体气质匹配
- 支持 React 直接引用，无需额外配置
- 开源免费，适合出海产品

## 7.2 图标尺寸

| Token | 尺寸 | 用途 |
|-------|------|------|
| `--icon-xs` | 12px | 内联小标记 |
| `--icon-sm` | 16px | 按钮内图标、表单提示 |
| `--icon-md` | 20px | 默认图标 |
| `--icon-lg` | 24px | 导航、操作栏 |
| `--icon-xl` | 32px | 空状态、功能入口 |

## 7.3 图标使用规则

- 同一按钮内图标与文字间距 8px
- 图标颜色默认继承文字颜色
- 不可用图标单独着色，除非作为状态指示
- 避免在同一界面使用超过 2 种不同风格的图标

## 7.4 常用图标映射

| 功能 | 图标 | 备注 |
|------|------|------|
| 文生图 | Sparkles | 首页主入口 |

| 生成 | Wand2 | 主按钮 |
| 下载 | Download | 结果卡片 |
| 复制 | Copy | 提示词 |

| 放大 | Maximize2 | 图片预览 |
| 关闭 | X | 模态框 / Toast |
| 设置 | Settings2 | 高级参数 |
| 历史 | History | 生成记录 |
| 升级 | Crown / Zap | 付费相关 |

## 7.5 空状态插画

使用简约几何插画而非真实图片：

- 线条风格，主色 --indigo-500
- 背景使用极淡的品牌渐变
- 文案 + 主按钮组合，引导用户行动

## 7.6 生成结果占位

生成过程中显示：

- 浅灰骨架屏，圆角 --radius-md
- 中央 spinner +「正在想象…」文案
- 进度百分比 caption 位于底部

## 7.7 装饰图形

### 光晕背景

```css
.glow {
  position: absolute;
  width: 600px;
  height: 600px;
  background: radial-gradient(circle, rgba(99,102,241,0.15) 0%, transparent 70%);
  filter: blur(60px);
  pointer-events: none;
}
```

用于首页 hero 与空状态背景，增加空间深度。

## 7.8 图片处理规范

- 所有展示图片使用 `object-fit: cover`
- 圆角统一为 --radius-md（小图）或 --radius-lg（大图）
- 暗色模式下图片容器可加 1px 半透明边框避免浮空感
