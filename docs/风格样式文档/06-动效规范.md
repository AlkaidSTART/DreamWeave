# 06 - 动效规范

## 6.1 动效哲学

动效服务于三个目标：

1. **解释状态**：让用户理解系统正在做什么
2. **引导注意**：突出新生成的结果或重要变化
3. **提升质感**：通过细腻动画传递高级感

所有动效必须可关闭（`prefers-reduced-motion`），且不影响功能可用性。

## 6.2 缓动曲线

| 名称 | 曲线 | 用途 |
|------|------|------|
| `--ease-smooth` | `cubic-bezier(0.4, 0, 0.2, 1)` | 默认过渡 |
| `--ease-out-expo` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场、展开 |
| `--ease-in-expo` | `cubic-bezier(0.7, 0, 0.84, 0)` | 退场、收缩 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 按钮点击、弹窗 |
| `--ease-linear` | `linear` | 循环进度动画 |

## 6.3 时长规范

| 类型 | 时长 | 说明 |
|------|------|------|
| 微交互 | 150ms | hover、焦点变化 |
| 标准过渡 | 200-300ms | 按钮、卡片、输入框 |
| 展开 / 折叠 | 300ms | 面板、手风琴 |
| 页面转场 | 400ms | 路由切换 |
| 结果出现 | 500ms | 生成图片淡入 |
| 强调动画 | 600-800ms | 成功庆祝、升级提示 |

## 6.4 微交互

### 按钮 Hover

```css
transition: transform 150ms var(--ease-smooth),
            box-shadow 150ms var(--ease-smooth),
            background-color 150ms var(--ease-smooth);
hover: translateY(-1px)
active: translateY(0) scale(0.98)
```

### 输入框 Focus

```css
transition: border-color 150ms, box-shadow 150ms;
focus: border-color --indigo-500, box-shadow 0 0 0 3px rgba(99,102,241,0.15)
```

### 卡片 Hover

```css
transition: box-shadow 200ms var(--ease-smooth), transform 200ms;
hover: box-shadow --shadow-md, translateY(-2px)
```

## 6.5 加载动画

### 生成中 Spinner

使用 3 个圆点呼吸动画，而非传统旋转圈：

```css
dot {
  width: 8px; height: 8px;
  border-radius: 50%;
  background: --indigo-500;
  animation: breathe 1.4s ease-in-out infinite;
}
dot:nth-child(2) { animation-delay: 0.2s; }
dot:nth-child(3) { animation-delay: 0.4s; }
```

### 骨架屏

```css
background: linear-gradient(90deg, --slate-100 0%, --slate-50 50%, --slate-100 100%);
background-size: 200% 100%;
animation: shimmer 1.5s infinite;
```

## 6.6 结果出现动画

生成完成的图片以 stagger 方式出现：

```css
.result-image {
  opacity: 0;
  transform: translateY(16px) scale(0.98);
  animation: reveal 500ms var(--ease-out-expo) forwards;
}
.result-image:nth-child(1) { animation-delay: 0ms; }
.result-image:nth-child(2) { animation-delay: 100ms; }
.result-image:nth-child(3) { animation-delay: 200ms; }
.result-image:nth-child(4) { animation-delay: 300ms; }
```

## 6.7 页面转场

Next.js 16 支持 View Transitions。主要页面切换使用淡入 + 轻微上滑：

```css
.page-enter {
  opacity: 0;
  transform: translateY(8px);
}
.page-enter-active {
  opacity: 1;
  transform: translateY(0);
  transition: opacity 300ms, transform 300ms var(--ease-out-expo);
}
```

## 6.8 禁忌

- 禁止大面积元素使用弹跳或摇晃动画
- 禁止加载动画超过 3 秒无进展提示
- 禁止动效阻断用户操作
- 禁止在 prefers-reduced-motion 下播放非必要动画
