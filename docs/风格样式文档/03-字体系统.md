# 03 - 字体系统

## 3.1 字体策略

采用「显示字体 + 正文字体」双字体策略，兼顾品牌个性与阅读效率。

| 用途 | 字体 | 来源 | 特征 |
|------|------|------|------|
| 显示 / 标题 | **Satoshi** | Fontshare（免费商用） | 几何感、现代、清晰 |
| 正文 / UI | **Geist Sans** | Next.js 内置 | 精密、高可读、科技 |
| 代码 / 标签 | **Geist Mono** | Next.js 内置 | 等宽、清晰、适合提示词展示 |

不使用系统默认无衬线字体作为标题，避免平庸感。

## 3.2 字体加载

```tsx
import { Geist, Geist_Mono } from "next/font/google";
import localFont from "next/font/local";

const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
});

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
});

const satoshi = localFont({
  src: "../public/fonts/Satoshi-Variable.woff2",
  variable: "--font-satoshi",
  display: "swap",
});
```

## 3.3 字号阶梯

| Token | 字号 | 行高 | 字重 | 字间距 | 用途 |
|-------|------|------|------|--------|------|
| `display-xl` | 56px / 3.5rem | 1.05 | 600 | -0.03em | 首页 hero 标题 |
| `display-lg` | 40px / 2.5rem | 1.1 | 600 | -0.02em | 页面大标题 |
| `display-md` | 32px / 2rem | 1.15 | 600 | -0.02em | 区块标题 |
| `heading-lg` | 24px / 1.5rem | 1.25 | 600 | -0.01em | 卡片标题 |
| `heading-md` | 20px / 1.25rem | 1.3 | 600 | -0.01em | 小标题 |
| `heading-sm` | 16px / 1rem | 1.35 | 600 | 0 | 列表标题 |
| `body-lg` | 18px / 1.125rem | 1.6 | 400 | 0 | 导语、重要正文 |
| `body-md` | 16px / 1rem | 1.6 | 400 | 0 | 默认正文 |
| `body-sm` | 14px / 0.875rem | 1.5 | 400 | 0 | 次要说明 |
| `caption` | 12px / 0.75rem | 1.4 | 500 | 0.01em | 标签、时间戳 |
| `mono-sm` | 13px / 0.8125rem | 1.5 | 400 | 0 | 提示词代码片段 |

## 3.4 字体组合规则

### 标题

```
font-family: var(--font-satoshi), var(--font-geist-sans), sans-serif;
font-weight: 600;
letter-spacing: -0.02em;
```

### 正文

```
font-family: var(--font-geist-sans), sans-serif;
font-weight: 400;
line-height: 1.6;
```

### 提示词 / 代码

```
font-family: var(--font-geist-mono), monospace;
font-size: 0.8125rem;
line-height: 1.5;
```

## 3.5 响应式字体

| 断点 | display-xl | display-lg | display-md |
|------|------------|------------|------------|
| 默认（移动端） | 36px | 30px | 24px |
| md (768px+) | 48px | 36px | 28px |
| lg (1024px+) | 56px | 40px | 32px |

## 3.6 排版禁忌

- 禁止正文使用小于 14px 的字号
- 禁止标题使用 font-weight 低于 600
- 禁止大段文字使用居中对齐（hero 区除外）
- 禁止一行超过 75 个字符（中文约 35 个）
