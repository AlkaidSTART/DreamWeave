# 12 - 无障碍与可访问性

## 12.1 目标

Dreamweave 致力于达到 **WCAG 2.2 Level AA** 标准，确保所有用户，包括使用屏幕阅读器、键盘导航、高对比度模式的用户，都能顺畅使用。

## 12.2 色彩对比度

| 元素 | 最低对比度 | 检查方式 |
|------|------------|----------|
| 正文文字 | 4.5:1 | 使用 WebAIM Contrast Checker |
| 大标题（24px+/18px bold） | 3:1 | 设计稿评审 |
| UI 组件边界 | 3:1 | 焦点状态、输入框边框 |
| 图标 | 3:1 | 与背景对比 |

## 12.3 焦点管理

- 所有交互元素必须有可见焦点环
- 焦点环使用 `--indigo-500`，宽度 2px，偏移 2px
- 焦点顺序遵循 DOM 顺序
- Modal 打开时焦点锁定在模态内，关闭后返回触发元素

```css
:focus-visible {
  outline: 2px solid --indigo-500;
  outline-offset: 2px;
}
```

## 12.4 键盘导航

- Tab 键可遍历所有功能
- Enter / Space 可激活按钮
- Esc 可关闭 Modal、Toast、下拉菜单
- 图片结果支持键盘聚焦与 Enter 预览

## 12.5 屏幕阅读器

- 所有图片必须有描述性 `alt` 文本
- 生成中的图片使用 `aria-busy="true"`
- 进度条使用 `role="progressbar"` + `aria-valuenow`
- 错误提示使用 `role="alert"` 或 `aria-live="polite"`
- 导航使用 `<nav>` 与 `aria-current="page"`

## 12.6 动画与运动

- 尊重 `prefers-reduced-motion: reduce`
- 减少动画时：
  - 淡入改为直接显示
  - 进度条过渡改为即时
  - 页面转场关闭

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 12.7 表单可访问性

- 每个输入框关联 `<label>`
- 使用 `aria-describedby` 关联错误提示
- placeholder 不替代 label
- 数量选择使用 radio group 语义

## 12.8 上传区域

- 拖拽区支持键盘触发文件选择
- 使用 `role="button"` + `tabIndex=0`
- 上传失败通过 Toast 与输入框错误状态双重提示
