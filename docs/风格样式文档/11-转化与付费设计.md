# 11 - 转化与付费设计

> **【暂缓实现 / v1.0.0 不涉及】**
>
> 当前阶段（MVP / 冷启动期）暂不实现任何付费相关 UI，包括付费墙、升级按钮、额度提示、定价页等。
>
> 本文档作为后续商业化阶段的预研规范保留，待产品验证完成后再进入开发排期。在此期间，所有生成能力均免费向用户开放，避免过早引入付费漏斗影响种子用户体验与口碑传播。

## 11.1 付费转化策略

设计目标：让用户在「体验到价值之后」自然产生付费意愿，而非通过强制弹窗打断流程。

### 核心原则

1. **先体验后付费**：免费用户可完成基础生成
2. **价值可视化**：明确展示付费带来的质量与效率提升
3. **低摩擦升级**：升级入口常驻但不干扰
4. **稀缺感合理**：每日额度、高级模型、批量生成等作为付费锚点

## 11.2 升级入口设计

### 导航栏升级按钮

```
位置: 右上角
文案: "升级 Pro"
样式: 琥珀 Upgrade Button，小号
状态: 免费用户常显，已登录付费用户隐藏
```

### 额度提示条

```
位置: 页面顶部或生成按钮下方
内容: "今日剩余 3/10 次免费生成"
样式: 进度条 + body-sm 文字
颜色: 充足时 --slate-600，不足时 --amber-500
```

## 11.3 付费墙设计

### 触发时机

- 免费额度耗尽时
- 尝试使用 Pro Skill 模板时
- 选择超过免费额度的生成数量时
- 批量导出超过限制时

### 付费墙样式

```
背景: --slate-0 / 暗色 --slate-900
边框: 1px solid --amber-200
顶部色条: 4px --amber-500
标题: "解锁无限创作"
副标题: 列出 Pro 权益
CTA: "升级 Pro" 琥珀按钮
关闭: 右上角 X，支持返回
```

### Pro 权益展示

| 权益 | 图标 | 说明 |
|------|------|------|
| 无限生成 | Zap | 不受每日额度限制 |
| 高清输出 | Maximize | 2K / 4K 分辨率 |
| 高级模型 | Sparkles | 更精致的生成质量 |
| 批量生成 | Layers | 一次最多 8 张 |
| 优先队列 | Rocket | 更快的生成速度 |

## 11.4 定价页设计

### 结构

```
标题: "选择适合你的创作计划"
月付 / 年付切换（年付高亮优惠）
三档卡片: Free / Pro / Team
  - Pro 卡片使用品牌渐变边框强调
常见问题 FAQ
CTA 区
```

### 卡片规范

```
推荐卡片: 边框 2px solid --indigo-500，顶部 "最受欢迎" 标签
非推荐卡片: 边框 1px solid --slate-200
价格字号: display-md
月付切换: 胶囊按钮组
```

## 11.5 信任信号

- 首页展示用户数量与生成图片数量
- 结果页显示生成耗时与模型信息
- 定价页展示安全支付图标
- 使用 Stripe / Paddle 等知名支付标识

## 11.6 转化文案规范

- 使用「解锁」「优先」「专属」等价值词
- 避免「限制」「禁止」等负面词
- CTA 文案具体：「升级到 Pro」优于「了解更多」
- 免费提示使用中性语气，不制造焦虑

## 11.7 A/B 测试建议

| 测试项 | 假设 | 指标 |
|--------|------|------|
| CTA 文案 | "开始创作" vs "免费生成" | 首页点击转化 |
| 付费墙触发时机 | 额度耗尽后 vs 生成 3 次后 | 升级率 |
| Pro 卡片顺序 | Pro 居中 vs Pro 居右 | 选择率 |
| 额度提示位置 | 顶部 vs 生成按钮旁 | 付费墙打开率 |
