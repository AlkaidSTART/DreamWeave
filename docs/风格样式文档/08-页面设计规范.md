# 08 - 页面设计规范

## 8.1 首页（Landing）

### 结构

```
导航栏
Hero 区
  - 标题："让想象触手可及"
  - 副标题："用文字或图片，在几秒内生成高质量视觉作品"
  - 主 CTA：开始创作
  - 次级 CTA：查看示例
功能展示
  - 文生图卡片
  - 图生图卡片
  - 提示词润色卡片
示例画廊
  - 6-8 张高质量生成样例
底部 CTA
  - "免费开始创作"
页脚
```

### Hero 区规范

- 背景：--slate-50 + 品牌光晕装饰
- 标题：display-xl，居中，Satoshi
- 副标题：body-lg，--slate-600，最大宽度 560px
- 主 CTA：Primary Button，高度 52px
- 次级 CTA：Secondary Button
- 上下内边距：--space-20

## 8.2 文生图页面

### 结构

```
返回 + 页面标题
提示词输入区（最大宽度 720px）
  - textarea
  - 字数统计
  - 清空按钮
Skill 模板横向滚动选择
生成参数
  - 数量选择（1/2/3/4）
  - 高级参数折叠面板
提交按钮（全宽，移动端）
结果展示区
```

### 设计要点

- 提示词输入区为视觉焦点，默认获得焦点
- Skill 卡片横向排列，支持点击选中
- 数量选择使用分段控制器（segmented control）
- 提交按钮在输入区下方，移动端全宽
- 结果区为空时展示引导插画

## 8.3 图生图页面

### 结构

```
页面标题
上传区域（拖拽 + 点击）
  - 空状态：上传图标 + 文案 + 支持格式提示
  - 已上传：缩略图 + 重新上传按钮
提示词输入区（可选）
Skill 模板选择
生成参数
提交按钮
结果展示区（含原图对比）
```

### 上传区域规范

```
最小高度: 200px
边框: 2px dashed --slate-300
圆角: --radius-lg
背景: --slate-50
dragover: 边框 --indigo-500，背景 --indigo-50
```

### 对比展示

- 结果页显示原图与生成图并排
- 移动端使用标签切换
- 提供「查看原图」入口

## 8.4 结果展示页面

### 结构

```
任务状态条（进度 + 状态文案）
结果网格
  - 1张：单图居中，最大宽度 720px
  - 2张：2 列
  - 3-4张：2×2 网格
单张操作栏
  - 下载
  - 放大预览
  - 复制提示词
  - 重新生成单张
提示词信息卡片
  - 原始提示词
  - 润色后提示词
  - 使用 Skill
```

### 状态条规范

- 固定于结果区顶部或页面顶部
- 包含：总进度条、状态文字、预计时间
- 失败时显示错误信息 + 重试按钮

## 8.5 导航规范

- 文生图 / 图生图页面使用一致页面框架
- 结果页 URL：`/result/[jobId]`
- 生成中允许离开页面，结果页通过 jobId 可重新访问
