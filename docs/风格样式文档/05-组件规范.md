# 05 - 组件规范

## 5.1 Button 按钮

### 主按钮 Primary

```
背景: --indigo-500
文字: white
高度: 44px（默认）/ 36px（small）/ 52px（large）
内边距: 0 20px
圆角: --radius-md (10px)
字体: body-md / font-weight 600
阴影: --shadow-md
hover: 背景 --indigo-600，y 轴 -1px，阴影 --shadow-lg
active: 背景 --indigo-700，y 轴 0
禁用: 背景 --slate-200，文字 --slate-400
```

### 次要按钮 Secondary

```
背景: transparent
边框: 1px solid --slate-200
文字: --slate-800
hover: 背景 --slate-50，边框 --slate-300
active: 背景 --slate-100
```

### 升级按钮 Upgrade（琥珀强调）

```
背景: --amber-500
文字: white
hover: --amber-600
阴影: 0 4px 14px rgba(245,158,11,0.3)
```

### 图标按钮

```
尺寸: 36px × 36px
圆角: --radius-md
背景: transparent
hover: 背景 --slate-100
```

## 5.2 Input 输入框

### 文本输入

```
高度: 自适应，最小 48px
内边距: 12px 16px
圆角: --radius-md
边框: 1px solid --slate-200
背景: --slate-0
字体: body-md
placeholder 颜色: --slate-400
focus: 边框 --indigo-500，外发光 --shadow-glow
错误: 边框 --error，背景 rgba(239,68,68,0.04)
```

### 提示词输入区 Prompt Input

```
最小高度: 120px
最大高度: 320px
圆角: --radius-lg
内边距: 16px
字号: body-md
行高: 1.7
右下角显示字数统计
```

## 5.3 Card 卡片

```
背景: --slate-0
圆角: --radius-lg
内边距: 24px
边框: 1px solid --slate-100
阴影: --shadow-sm
hover: 阴影 --shadow-md（可选）
```

### 结果卡片 Result Card

```
背景: --slate-50
圆角: --radius-lg
内边距: 12px
图片圆角: --radius-md
底部操作栏: 40px 高，图标按钮排列
```

## 5.4 Progress 进度条

```
轨道高度: 6px
轨道背景: --slate-100
填充色: --indigo-500
圆角: full
过渡: width 300ms ease-out
百分比文字: caption，--slate-600
```

### 多图进度

为每张生成图片显示独立细进度条，或在总进度条下方显示小圆点状态。

## 5.5 Toast 轻提示

```
最大宽度: 360px
圆角: --radius-lg
内边距: 14px 16px
阴影: --shadow-xl
位置: 右上角，距边缘 24px
成功: 左侧 4px --mint-500 色条
错误: 左侧 4px --error 色条
信息: 左侧 4px --indigo-500 色条
```

## 5.6 Modal 模态框

```
遮罩: rgba(0,0,0,0.4)，backdrop-blur 4px
容器最大宽度: 480px（确认）/ 720px（大图预览）
圆角: --radius-xl
内边距: 24px
入场: scale 0.96 → 1，opacity 0 → 1，200ms
```

## 5.7 Skill 模板卡片

```
尺寸: 160px × auto（移动端 140px）
圆角: --radius-lg
边框: 1px solid --slate-200
选中态: 边框 --indigo-500，外发光 --shadow-glow
缩略图: 4:3，圆角 --radius-md
标题: heading-sm
描述: body-sm，单行截断
```

## 5.8 导航栏

```
高度: 64px
背景: 透明（首页）/ --slate-0/80 backdrop-blur（滚动后）
内容最大宽度: --container-2xl
左侧: Logo
中间: 页面导航
右侧: 用户头像 / 升级按钮
```
