# 09 - 暗色模式

## 9.1 设计策略

暗色模式不是简单反色，而是重新构建「深夜画廊」氛围：

- 背景使用深灰而非纯黑，避免 OLED 刺眼与图片边缘锯齿
- 品牌主色在暗色下提升亮度，保持鲜明
- 阴影转为发光，维持层级感
- 图片展示容器加细边框，防止与背景融合

## 9.2 实现方式

使用 Tailwind CSS 4 的 `@custom-variant` 实现 class 驱动切换：

```css
@custom-variant dark (&:where(.dark, .dark *));
```

在 `<html>` 上动态切换 `dark` class，支持：

1. 跟随系统 `prefers-color-scheme`
2. 用户手动切换
3. 记住用户选择（localStorage）

## 9.3 Token 映射

| 用途 | 亮色 Token | 暗色 Token |
|------|------------|------------|
| 页面背景 | `--bg-page: --slate-50` | `--bg-page: --slate-950` |
| 卡片背景 | `--bg-card: --slate-0` | `--bg-card: --slate-900` |
|  elevate 背景 | `--bg-elevate: --slate-100` | `--bg-elevate: --slate-800` |
| 主文字 | `--text-primary: --slate-900` | `--text-primary: --slate-50` |
| 次要文字 | `--text-secondary: --slate-600` | `--text-secondary: --slate-400` |
| 第三文字 | `--text-tertiary: --slate-400` | `--text-tertiary: --slate-500` |
| 主边框 | `--border: --slate-200` | `--border: rgba(255,255,255,0.08)` |
| 强调边框 | `--border-accent: --indigo-200` | `--border-accent: --indigo-700` |
| 主按钮 | `--indigo-500` | `--indigo-400` |

## 9.4 组件暗色适配

### 卡片

- 背景 --bg-card
- 边框 --border
- hover 时轻微发光而非加深阴影

### 输入框

- 背景 --slate-900（暗色）
- 边框 rgba(255,255,255,0.1)
- focus 外发光颜色降低透明度

### 按钮

- Primary 按钮使用 --indigo-400，hover --indigo-300
- Secondary 按钮边框 rgba(255,255,255,0.15)

### 阴影转发光

```css
.dark .card-hover {
  box-shadow: 0 0 24px rgba(99,102,241,0.12);
}
```

## 9.5 切换控件

- 使用太阳 / 月亮图标按钮
- 放置于导航栏右侧
- 切换动画时长 200ms

## 9.6 测试要求

- 所有页面必须在暗色模式下检查对比度
- 图片展示区域必须清晰可见，不浮空
- 二维码 / 图表等第三方内容需单独适配
