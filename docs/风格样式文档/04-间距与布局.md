# 04 - 间距与布局

## 4.1 间距 Scale

使用 4px 基数的扩展间距系统，便于 Tailwind 直接使用。

| Token | 值 | Tailwind | 用途 |
|-------|-----|----------|------|
| `--space-0_5` | 2px | `0.5` | 极细缝隙 |
| `--space-1` | 4px | `1` | 图标与文字间距 |
| `--space-2` | 8px | `2` | 紧凑内联间距 |
| `--space-3` | 12px | `3` | 表单元素之间 |
| `--space-4` | 16px | `4` | 默认组件内边距 |
| `--space-5` | 20px | `5` | 卡片内边距 |
| `--space-6` | 24px | `6` | 区块内部间距 |
| `--space-8` | 32px | `8` | 卡片之间 |
| `--space-10` | 40px | `10` | 页面区块间距 |
| `--space-12` | 48px | `12` | 大区块分隔 |
| `--space-16` | 64px | `16` | 页面 section 间距 |
| `--space-20` | 80px | `20` | hero 区上下间距 |
| `--space-24` | 96px | `24` | 最大区块间距 |

## 4.2 圆角 Scale

| Token | 值 | Tailwind | 用途 |
|-------|-----|----------|------|
| `--radius-sm` | 6px | `rounded-md` | 小标签、输入框 |
| `--radius-md` | 10px | `rounded-lg` | 按钮、小卡片 |
| `--radius-lg` | 16px | `rounded-2xl` | 卡片、面板 |
| `--radius-xl` | 24px | `rounded-3xl` | 大卡片、模态框 |
| `--radius-full` | 9999px | `rounded-full` | 头像、 pill 标签 |

## 4.3 阴影 Scale

```css
--shadow-sm: 0 1px 2px rgba(0,0,0,0.04);
--shadow-md: 0 4px 12px rgba(0,0,0,0.06);
--shadow-lg: 0 12px 32px rgba(0,0,0,0.08);
--shadow-xl: 0 24px 56px rgba(0,0,0,0.12);
--shadow-glow: 0 0 24px rgba(99,102,241,0.24);
--shadow-inner-light: inset 0 1px 0 rgba(255,255,255,0.6);
```

暗色模式下阴影应减弱，改为发光效果替代。

## 4.4 布局网格

### 容器宽度

| Token | 最大宽度 | 用途 |
|-------|----------|------|
| `--container-sm` | 640px | 窄内容页 |
| `--container-md` | 768px | 表单页 |
| `--container-lg` | 1024px | 标准内容页 |
| `--container-xl` | 1280px | 结果展示页 |
| `--container-2xl` | 1440px | 首页 hero |

### 页面内边距

```css
--page-padding-x: 16px;  /* 移动端 */
--page-padding-x-md: 24px;  /* 平板 */
--page-padding-x-lg: 32px;  /* 桌面 */
--page-padding-x-xl: 48px;  /* 大屏 */
```

### 内容区结构

典型页面采用「居中窄输入 + 宽结果展示」结构：

```
┌────────────────────────────────────────────┐
│              顶部导航栏（固定）              │
├────────────────────────────────────────────┤
│                                            │
│            标题 + 副标题（居中）              │
│                                            │
├────────────────────────────────────────────┤
│                                            │
│         工具面板（最大宽度 720px）            │
│                                            │
├────────────────────────────────────────────┤
│                                            │
│         结果展示区（最大宽度 1280px）         │
│                                            │
└────────────────────────────────────────────┘
```

## 4.5 断点系统

| 名称 | 宽度 | 设备 |
|------|------|------|
| `sm` | 640px | 大手机 |
| `md` | 768px | 平板 |
| `lg` | 1024px | 小笔记本 |
| `xl` | 1280px | 桌面 |
| `2xl` | 1536px | 大屏 |

## 4.6 间距使用原则

- 相关元素间距小（8-12px），无关元素间距大（32-64px）
- 卡片内部统一使用 20px 或 24px 内边距
- 同一垂直流中的组件间距应为 8 的倍数
- 避免使用 14px、18px 等不规律间距
