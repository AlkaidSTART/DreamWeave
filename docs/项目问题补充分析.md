### 14. Redis 连接配置不符合错误处理约束 ⚠️

**位置**: `lib/redis.ts`

**问题描述**:
当前 Redis 配置：
```typescript
export const redis = new Redis(url, {
  maxRetriesPerRequest: null,
  enableReadyCheck: false,
});
```

**存在的严重问题**:
1. `maxRetriesPerRequest: null` - 无限重试单个请求，可能导致请求永久挂起
2. `enableReadyCheck: false` - 跳过连接健康检查，无法及时发现连接问题
3. 缺少 `retryStrategy` - 不符合"指数退避"的错误处理约束
4. 缺少连接事件监听器（error、connect、close）
5. 启动时直接抛出错误而非优雅降级

**影响**:
- ❌ 违反 `harness/rules/project/07-错误处理约束.md` 中的重试策略要求
- ❌ Redis 故障时应用直接崩溃，缺少容错机制
- ❌ 无法监控 Redis 连接状态，生产环境排查困难

**修复建议**:
```typescript
// lib/redis.ts
import { Redis } from "ioredis";

function createRedisConnection(): Redis {
  const url = process.env.REDIS_URL;
  if (!url) {
    throw new Error("缺少 REDIS_URL 环境变量");
  }

  const redis = new Redis(url, {
    maxRetriesPerRequest: 3,
    enableReadyCheck: true,
    retryStrategy: (times) => {
      const delay = Math.min(times * 50, 2000);
      console.log(`[Redis] 重试连接 (${times}次)，等待 ${delay}ms`);
      return delay;
    },
    lazyConnect: false,
  });

  redis.on('error', (err) => {
    console.error('[Redis] 连接错误:', err.message);
  });

  redis.on('connect', () => {
    console.log('[Redis] 已连接');
  });

  redis.on('close', () => {
    console.warn('[Redis] 连接已关闭');
  });

  redis.on('reconnecting', () => {
    console.log('[Redis] 正在重新连接...');
  });

  return redis;
}

export const redis = createRedisConnection();
```

### 16. 缺少前端请求超时和重试机制

**位置**: `lib/api.ts`

**问题描述**:
前端 API 请求存在以下问题：

1. **fetch 请求无超时**: 可能导致请求永久挂起
2. **SSE 连接无重连**: EventSource 断开后不会自动重连
3. **无错误重试**: 网络临时故障时不会重试

**影响**:
- 用户体验差，长时间无响应
- 网络不稳定时频繁失败
- 违反错误处理约束

**修复建议**:

```typescript
// lib/api.ts
const DEFAULT_TIMEOUT = 30000;
const MAX_RETRIES = 3;

// 1. 添加超时控制
async function fetchWithTimeout(
  url: string,
  options: RequestInit = {},
  timeout = DEFAULT_TIMEOUT
): Promise<Response> {
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), timeout);

  try {
    const response = await fetch(url, {
      ...options,
      signal: controller.signal,
    });
    return response;
  } finally {
    clearTimeout(timeoutId);
  }
}

// 2. 添加重试机制
async function fetchWithRetry(
  url: string,
  options: RequestInit = {},
  retries = MAX_RETRIES
): Promise<Response> {
  try {
    return await fetchWithTimeout(url, options);
  } catch (error) {
    if (retries > 0 && shouldRetry(error)) {
      await delay(1000);
      return fetchWithRetry(url, options, retries - 1);
    }
    throw error;
  }
}

function shouldRetry(error: unknown): boolean {
  if (error instanceof Error && error.name === 'AbortError') {
    return false; // 超时不重试
  }
  return true;
}

// 3. SSE 自动重连
export function subscribeJobProgress(
  jobId: string,
  onUpdate: (data: ProgressData) => void,
  maxRetries = 3
) {
  let retryCount = 0;
  let eventSource: EventSource | null = null;
  let reconnectTimer: NodeJS.Timeout | null = null;

  const connect = () => {
    eventSource = new EventSource(`/api/jobs/${jobId}/stream`);
    
    eventSource.addEventListener('progress', (e) => {
      const data = JSON.parse(e.data);
      onUpdate(data);
      retryCount = 0; // 重置重试计数
    });

    eventSource.onerror = () => {
      eventSource?.close();
      
      if (retryCount < maxRetries) {
        retryCount++;
        const delay = Math.min(retryCount * 1000, 5000);
        console.log(`[SSE] 连接断开，${delay}ms 后重试 (${retryCount}/${maxRetries})`);
        
        reconnectTimer = setTimeout(connect, delay);
      } else {
        console.error('[SSE] 达到最大重试次数，停止重连');
      }
    };
  };

  connect();

  return () => {
    if (reconnectTimer) clearTimeout(reconnectTimer);
    eventSource?.close();
  };
}
```

### 17. 日志记录不完整且缺少结构化格式

**位置**: 全局

**问题描述**:
代码中仅使用简单的 `console.log` 和 `console.error`，不符合 `harness/rules/project/07-错误处理约束.md` 的要求。

**当前日志示例**:
```typescript
console.log(`[imageWorker] job ${job?.id} completed`);
console.error(`[imageWorker] job ${job?.id} failed: ${err.message}`);
```

**缺少的关键信息**:
- ❌ 时间戳
- ❌ 日志级别
- ❌ 上下文信息（用户ID、请求ID）
- ❌ 完整的错误堆栈
- ❌ 结构化格式（无法被日志收集工具解析）

**修复建议**:

创建统一的日志工具：

```typescript
// lib/logger.ts
type LogLevel = 'debug' | 'info' | 'warn' | 'error';

interface LogContext {
  timestamp: string;
  level: LogLevel;
  message: string;
  context?: Record<string, unknown>;
  error?: {
    message: string;
    stack?: string;
    code?: string;
  };
}

class Logger {
  private shouldLog(level: LogLevel): boolean {
    const levels = ['debug', 'info', 'warn', 'error'];
    const minLevel = process.env.LOG_LEVEL || 'info';
    return levels.indexOf(level) >= levels.indexOf(minLevel);
  }

  private log(
    level: LogLevel,
    message: string,
    context?: Record<string, unknown>,
    error?: Error
  ) {
    if (!this.shouldLog(level)) return;

    const logData: LogContext = {
      timestamp: new Date().toISOString(),
      level,
      message,
      context,
    };

    if (error) {
      logData.error = {
        message: error.message,
        stack: error.stack,
        code: (error as any).code,
      };
    }

    const logStr = JSON.stringify(logData);
    
    switch (level) {
      case 'error':
        console.error(logStr);
        break;
      case 'warn':
        console.warn(logStr);
        break;
      default:
        console.log(logStr);
    }
  }

  debug(message: string, context?: Record<string, unknown>) {
    this.log('debug', message, context);
  }

  info(message: string, context?: Record<string, unknown>) {
    this.log('info', message, context);
  }

  warn(message: string, context?: Record<string, unknown>) {
    this.log('warn', message, context);
  }

  error(message: string, error: Error, context?: Record<string, unknown>) {
    this.log('error', message, context, error);
  }
}

export const logger = new Logger();
```

**使用示例**:
```typescript
// 替换
console.log(`[imageWorker] job ${job?.id} completed`);

// 为
logger.info('Image generation job completed', {
  jobId: job.id,
  userId: job.userId,
  duration: Date.now() - startTime,
});

// 替换
console.error(`[imageWorker] job ${job?.id} failed: ${err.message}`);

// 为

  jobId: job.id,
  userId: job.userId,
});
```

### 18. 缺少速率限制保护 🔒

**位置**: 所有 API 路由

**问题描述**:
API 路由未实现速率限制，存在严重安全风险：

| API 路由 | 风险类型 | 影响 |
|----------|----------|------|
| `/api/auth/login` | 暴力破解 | 账号被盗 |
| `/api/generate` | 资源耗尽 | 队列拥堵，影响所有用户 |
| `/api/upload` | DoS 攻击 | 存储空间被占满 |
| `/api/refine` | API 配额滥用 | 大模型 API 费用激增 |

**修复建议**:

实现基于 Redis 的速率限制中间件：

```typescript
// lib/rate-limit.ts
import { redis } from '@/lib/redis';
import { NextRequest, NextResponse } from 'next/server';

interface RateLimitConfig {
  windowMs: number;
  maxRequests: number;
}

export async function rateLimit(
  identifier: string,
  config: RateLimitConfig
): Promise<{ allowed: boolean; remaining: number; resetAt: number }> {
  const key = `ratelimit:${identifier}`;
  const now = Date.now();
  const windowStart = now - config.windowMs;

  const pipeline = redis.pipeline();
  pipeline.zremrangebyscore(key, 0, windowStart);
  pipeline.zadd(key, now, `${now}-${Math.random()}`);
  pipeline.zcard(key);
  pipeline.expire(key, Math.ceil(config.windowMs / 1000));

  const results = await pipeline.exec();
  const count = results?.[2]?.[1] as number;

  return {
    allowed: count <= config.maxRequests,
    remaining: Math.max(0, config.maxRequests - count),
    resetAt: now + config.windowMs,
  };
}

export function getRateLimitHeaders(limit: Awaited<ReturnType<typeof rateLimit>>) {
  return {
    'X-RateLimit-Limit': String(limit.remaining + (limit.allowed ? 1 : 0)),
    'X-RateLimit-Remaining': String(limit.remaining),
    'X-RateLimit-Reset': new Date(limit.resetAt).toISOString(),
  };
}
```

**在 middleware.ts 中应用**:
```typescript
// middleware.ts
import { rateLimit, getRateLimitHeaders } from '@/lib/rate-limit';

export async function middleware(request: NextRequest) {
  const ip = request.ip || request.headers.get('x-forwarded-for') || 'unknown';
  const pathname = request.nextUrl.pathname;

  // 登录接口：每分钟最多 5 次请求
  if (pathname === '/api/auth/login') {
    const limit = await rateLimit(`login:${ip}`, {
      windowMs: 60000,
      maxRequests: 5,
    });

    if (!limit.allowed) {
      return NextResponse.json(
        { error: '登录请求过于频繁，请稍后再试' },
        { 
          status: 429,
          headers: getRateLimitHeaders(limit),
        }
      );
    }
  }

  // 生成接口：每分钟最多 10 次请求
  if (pathname === '/api/generate') {
    const limit = await rateLimit(`generate:${ip}`, {
      windowMs: 60000,
      maxRequests: 10,
    });

    if (!limit.allowed) {
      return NextResponse.json(
        { error: '生成请求过于频繁，请稍后再试' },
        { 
          status: 429,
          headers: getRateLimitHeaders(limit),
        }
      );
    }
  }

  return NextResponse.next();
}
```

### 20. 缺少前端错误边界

**位置**: React 组件

**问题描述**:
React 组件未实现 Error Boundary，运行时错误会导致整个应用白屏崩溃，用户体验极差。

**修复建议**:

```typescript
// components/error-boundary.tsx
'use client';

import { Component, type ReactNode } from 'react';

interface Props {
  children: ReactNode;
  fallback?: ReactNode;
  onError?: (error: Error, errorInfo: unknown) => void;
}

interface State {
  hasError: boolean;
  error?: Error;
}

export class ErrorBoundary extends Component<Props, State> {
  constructor(props: Props) {
    super(props);
    this.state = { hasError: false };
  }

  static getDerivedStateFromError(error: Error): State {
    return { hasError: true, error };
  }

  componentDidCatch(error: Error, errorInfo: unknown) {
    console.error('ErrorBoundary caught:', error, errorInfo);
    this.props.onError?.(error, errorInfo);
  }

  render() {
    if (this.state.hasError) {
      return (
        this.props.fallback || (
          <div className="flex min-h-screen items-center justify-center p-4">
            <div className="text-center">
              <h2 className="text-2xl font-bold">出错了</h2>
              <p className="mt-2 text-muted-foreground">
                {this.state.error?.message || '发生了未知错误'}
              </p>
              <button
                onClick={() => window.location.reload()}
                className="mt-4 rounded-lg bg-primary px-4 py-2 text-primary-foreground"
              >
                刷新页面
              </button>
            </div>
          </div>
        )
      );
    }

    return this.props.children;
  }
}
```

**在 `app/layout.tsx` 中使用**:
```typescript
import { ErrorBoundary } from '@/components/error-boundary';

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html>
      <body>
        <ErrorBoundary>
          {children}
        </ErrorBoundary>
      </body>
    </html>
  );
}
```

### 21. 缺少图片加载失败的降级处理

**位置**: `components/result-view.tsx`, `components/image-result-card.tsx`

**问题描述**:
使用 Next.js `Image` 组件但未提供 `onError` 回调，图片加载失败时显示空白或损坏图标，用户体验差。

**修复建议**:

```typescript
// components/image-with-fallback.tsx
import Image, { type ImageProps } from 'next/image';
import { useState } from 'react';
import { ImageIcon } from 'lucide-react';

export function ImageWithFallback({ 
  src, 
  alt, 
  ...props 
}: ImageProps) {
  const [error, setError] = useState(false);

  if (error || !src) {
    return (
      <div className="flex items-center justify-center bg-muted">
        <div className="text-center text-muted-foreground">
          <ImageIcon className="mx-auto h-12 w-12" />
          <p className="mt-2 text-sm">图片加载失败</p>
        </div>
      </div>
    );
  }

  return (
    <Image
      src={src}
      alt={alt}
      {...props}
      onError={() => setError(true)}
    />
  );
}
```
