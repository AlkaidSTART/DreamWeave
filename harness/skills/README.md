# Harness Skills 目录说明

## 概述

本目录是**约束体系**的一部分，用于定义项目的技能和能力框架。

## 与 src/skills 的区别

| 目录 | 用途 | 内容 |
|------|------|------|
| `harness/skills/` | 约束体系中的技能定义 | 定义开发团队的技能要求、培训计划、能力矩阵 |
| `src/skills/` | 业务层的提示词模板 | 定义AI生图的提示词模板（摄影、插画、电影、动漫等） |

## 目录结构

```
harness/skills/
├── README.md              # 本文件，说明文档
├── skills-matrix.md       # 技能矩阵（预留）
├── training-plan.md       # 培训计划（预留）
└── competency-levels.md   # 能力等级定义（预留）
```

## 未来规划

本目录目前为预留状态，未来可根据团队需求添加以下内容：

### 技能矩阵
定义开发团队的技能要求和评估标准

### 培训计划
定义技术培训计划和学习路径

### 能力等级定义
定义不同技能的能力等级标准
