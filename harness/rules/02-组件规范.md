# 编码规范 - 组件规范

## Server Components vs Client Components

- **默认Server Components**: 所有组件默认为Server Components
- **显式声明**: 需要客户端交互时，在文件顶部添加`'use client'`
- **混合使用**: Server Components可以导入Client Components，反之不行

```tsx
// Server Component (默认)
async function Page() {
  const data = await fetchData();
  return <ClientComponent data={data} />;
}

// Client Component (显式声明)
'use client';

function ClientComponent({ data }) {
  const [count, setCount] = useState(0);
  return <div>{data}</div>;
}
```

## 组件设计原则

- **单一职责**: 每个组件只负责一个功能
- **可复用性**: 设计可复用的通用组件
- **Props最小化**: 只传递必要的Props
- **条件渲染**: 使用三元运算符或逻辑运算符进行条件渲染

```tsx
function Button({ children, disabled }) {
  return (
    <button
      disabled={disabled}
      className={`px-4 py-2 rounded ${disabled ? 'opacity-50' : 'hover:opacity-90'}`}
    >
      {children}
    </button>
  );
}
```

## Hooks使用规范

- **自定义Hooks**: 以`use`开头命名
- **Hook规则**: 只在组件顶层调用Hook
- **useState**: 状态变量命名使用`set`前缀
- **useEffect**: 明确依赖数组，避免无限循环

```typescript
function useCounter(initialValue = 0) {
  const [count, setCount] = useState(initialValue);
  
  const increment = () => setCount(c => c + 1);
  const decrement = () => setCount(c => c - 1);
  
  return { count, increment, decrement };
}
```
