# 编码规范 - 队列层规范

## Queue配置

- **队列命名**: 使用描述性名称（如`image-generation`）
- **默认配置**: 在`src/queue/queue.ts`中配置默认选项
- **任务选项**: 为每个任务类型定义默认选项

```typescript
import { Queue } from 'bullmq';
import { redisConnection } from '../lib/redis';

export const imageGenerationQueue = new Queue('image-generation', {
  connection: redisConnection,
  defaultJobOptions: {
    attempts: 3,
    backoff: {
      type: 'exponential',
      delay: 1000,
    },
    removeOnComplete: {
      age: 86400,
    },
    removeOnFail: {
      age: 86400,
    },
  },
});
```

## Worker配置

- **并发数**: 根据服务器资源配置并发数
- **处理器分离**: 将处理器逻辑放在单独的文件中
- **事件监听**: 监听`completed`/`failed`事件

```typescript
import { Worker } from 'bullmq';
import { processor } from './processor';
import { redisConnection } from '../lib/redis';

export const worker = new Worker('image-generation', processor, {
  connection: redisConnection,
  concurrency: 4,
});

worker.on('completed', (job) => {
  console.log(`Job ${job.id} completed`);
});

worker.on('failed', (job, err) => {
  console.error(`Job ${job.id} failed: ${err.message}`);
});
```
