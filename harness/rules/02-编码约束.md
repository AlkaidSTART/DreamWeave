# 项目约束 - 编码约束

## 2.1 语言规范

- **TypeScript**: 项目必须使用TypeScript，禁止使用JavaScript
- **严格模式**: `tsconfig.json`必须启用`strict: true`
- **ESLint**: 必须通过ESLint检查，禁止跳过lint规则

## 2.2 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 文件 | 小写+连字符 | `prompt-service.ts` |
| 组件 | PascalCase | `TextToImageForm.tsx` |
| 函数 | camelCase | `generateImage()` |
| 变量 | camelCase | `imageCount` |
| 常量 | UPPER_SNAKE_CASE | `MAX_FILE_SIZE` |
| 类型/接口 | PascalCase | `GenerationJob` |
| 枚举 | PascalCase | `JobStatus` |

## 2.3 组件规范

- **Server Components**: 默认使用服务端组件，仅在需要交互时使用`'use client'`
- **组件职责**: 单一职责原则，组件代码不超过200行
- **Props定义**: 必须使用TypeScript接口定义Props
- **无副作用**: Server Components禁止使用useState/useEffect

## 2.4 API规范

- **RESTful风格**: API路径使用名词复数，HTTP方法使用标准语义
- **错误处理**: 统一错误响应格式，包含error和message字段
- **状态码**: 使用标准HTTP状态码（200/400/404/500）
- **响应格式**: 统一JSON响应格式
