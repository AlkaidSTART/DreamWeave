# 架构约束 - 安全架构约束

## 6.1 网络安全约束

**约束**:
- 生产环境必须使用HTTPS
- API接口必须配置CORS
- 禁止在前端暴露敏感信息（API密钥等）
- 外部服务调用必须在后端执行

## 6.2 输入安全约束

**约束**:
- 所有用户输入必须验证
- 禁止信任用户提供的文件名
- 必须过滤特殊字符和危险输入
- 文件上传必须验证文件类型和大小

**验证流程**:
```
用户输入 → 前端验证 → 后端验证 → 业务处理
```

## 6.3 数据安全约束

**约束**:
- API密钥必须使用环境变量存储
- 禁止在日志中记录敏感信息
- 生成的图片必须存储在安全位置
- 历史记录必须定期清理
