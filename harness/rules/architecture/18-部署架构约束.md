# 架构约束 - 部署架构约束

## 8.1 环境约束

| 环境 | 配置要求 | 约束 |
|------|----------|------|
| 开发 | 本地环境，Redis本地 | 允许跳过部分安全检查 |
| 测试 | 独立环境，Redis独立 | 必须通过所有测试 |
| 生产 | 云环境，Redis集群 | 必须启用所有安全检查 |

## 8.2 容器化约束

**约束**:
- 应用必须支持Docker容器化部署
- Docker镜像必须使用多阶段构建
- 容器必须以非root用户运行
- 必须设置资源限制

**Dockerfile示例**:
```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production

FROM node:20-alpine
WORKDIR /app
COPY --from=builder /app/node_modules ./node_modules
COPY . .
USER node
ENV NODE_ENV=production
EXPOSE 3000
CMD ["npm", "start"]
```

## 8.3 进程管理约束

**约束**:
- 主进程和Worker进程必须独立部署
- 进程必须配置自动重启
- 必须监控进程健康状态
- 必须配置优雅关闭

**PM2配置示例**:
```json
{
  "apps": [
    {
      "name": "dreamweave-app",
      "script": "node_modules/.bin/next start",
      "instances": "max",
      "exec_mode": "cluster",
      "env": { "NODE_ENV": "production" }
    },
    {
      "name": "dreamweave-worker",
      "script": "worker.js",
      "instances": 4,
      "exec_mode": "fork",
      "env": { "NODE_ENV": "production" }
    }
  ]
}
```
