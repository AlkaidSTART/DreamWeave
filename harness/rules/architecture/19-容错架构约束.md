# 架构约束 - 容错架构约束

## 9.1 故障处理约束

**约束**:
- 所有外部调用必须有超时设置
- 所有外部调用必须有重试机制
- 任务失败必须记录错误信息
- 必须提供重试和取消任务的功能

## 9.2 降级策略

**约束**:
- 外部服务不可用时，必须提供降级方案
- 降级方案必须提前定义和测试
- 降级状态必须通知用户

**降级场景**:
| 场景 | 降级策略 | 用户通知 |
|------|----------|----------|
| AI生图API不可用 | 返回错误提示 | "服务暂时不可用，请稍后重试" |
| 大模型API不可用 | 使用原始提示词 | "提示词优化暂时不可用，将使用原始提示词" |
| Redis不可用 | 拒绝新请求 | "服务暂时不可用，请稍后重试" |

## 9.3 数据一致性约束

**约束**:
- 任务状态和文件存储必须保持一致
- 任务失败时必须清理已生成的文件
- 必须定期检查不一致状态并修复
