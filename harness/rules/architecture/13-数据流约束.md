# 架构约束 - 数据流约束

## 3.1 请求数据流

**文生图数据流**:
```
用户输入提示词 → 前端验证 → POST /api/generate → Queue.add() → 返回jobId
                                                              │
                                                              ▼
                                                    Worker.process() → PromptService.refine()
                                                              │
                                                              ▼
                                                    AI生图API.generate() → 保存图片 → 更新进度
                                                              │
                                                              ▼
                                                    前端轮询/SSE → 获取结果 → 展示图片
```

**图生图数据流**:
```
用户上传图片 → POST /api/upload → 保存文件 → 返回图片URL

用户输入提示词 → 前端验证 → POST /api/generate (含图片URL) → Queue.add() → 返回jobId
                                                                                    │
                                                                                    ▼
                                                                          Worker.process() → AI生图API.generateWithImage()
                                                                                    │
                                                                                    ▼
                                                                          保存图片 → 更新进度 → 前端获取结果
```

## 3.2 数据存储约束

| 数据类型 | 存储方式 | 存储位置 | 约束 |
|----------|----------|----------|------|
| 任务状态 | Key-Value | Redis Hash | 任务ID作为Key |
| 任务队列 | Queue | BullMQ | 必须持久化 |
| 生成结果 | 文件 | 文件系统/对象存储 | 按任务ID分目录 |
| 上传文件 | 文件 | 文件系统/对象存储 | 临时存储24小时 |
| 历史记录 | List | Redis List | 限制100条 |

## 3.3 文件存储结构约束

```
public/
└── uploads/
    ├── [jobId]/
    │   ├── input/          # 上传的输入图片（图生图）
    │   │   └── original.png
    │   └── output/         # 生成的结果图片
    │       ├── img-1.png
    │       ├── img-2.png
    │       ├── img-3.png
    │       └── img-4.png
    └── temp/               # 临时文件（定期清理）
```

**约束**:
- 每个任务必须使用独立目录
- 文件名必须使用UUID或安全字符
- 禁止使用用户提供的原始文件名
- 临时文件必须在24小时内清理
