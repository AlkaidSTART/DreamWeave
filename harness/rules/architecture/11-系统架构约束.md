# 架构约束 - 系统架构约束

## 1.1 架构风格

**约束**: 采用分层单体架构（Layered Monolith）

```
┌─────────────────────────────────────────────────────────────────┐
│                        前端层 (Next.js)                          │
│  Server Components + Client Components                          │
└───────────────────┬─────────────────────────────────────────────┘
                    │ HTTP/REST
                    ▼
┌─────────────────────────────────────────────────────────────────┐
│                        API层 (Route Handlers)                    │
│  请求路由、参数验证、响应格式化                                    │
└───────────────────┬─────────────────────────────────────────────┘
                    │ BullMQ
                    ▼
┌─────────────────────────────────────────────────────────────────┐
│                      队列层 (BullMQ + Redis)                      │
│  任务管理、并发控制、重试机制                                      │
└───────────────────┬─────────────────────────────────────────────┘
                    │ 外部API调用
                    ▼
┌─────────────────────────────────────────────────────────────────┐
│                      外部服务层                                  │
│  AI生图API + 大模型API                                          │
└─────────────────────────────────────────────────────────────────┘
```

**约束说明**:
- 禁止跳过中间层直接访问下层服务
- API层禁止直接调用外部服务，必须通过队列层
- 前端层禁止直接访问Redis或外部服务

## 1.2 模块划分约束

| 模块 | 路径 | 职责 | 约束 |
|------|------|------|------|
| 前端页面 | `app/` | 用户界面、页面路由 | Server Components默认 |
| API路由 | `app/api/` | REST API端点 | 无业务逻辑 |
| 队列配置 | `src/queue/` | Queue和Worker配置 | 必须使用BullMQ |
| 服务层 | `src/services/` | 业务逻辑、外部调用 | 禁止直接操作文件系统 |
| Skill层 | `src/skills/` | 提示词模板管理 | 无状态设计 |
| 工具库 | `src/lib/` | 通用工具、配置管理 | 无副作用 |
| 类型定义 | `src/types/` | TypeScript类型定义 | 严格类型检查 |
