# 项目约束 - 代码质量约束

## 8.1 代码审查

- 所有代码提交必须经过代码审查
- 代码审查必须检查：类型安全、错误处理、性能、安全性
- 禁止跳过代码审查直接合并

## 8.2 CI/CD检查

| 检查项 | 工具 | 强制要求 |
|--------|------|----------|
| TypeScript类型检查 | tsc | 是 |
| ESLint检查 | eslint | 是 |
| 单元测试 | vitest | 是 |
| 集成测试 | vitest | 是 |
| 构建检查 | next build | 是 |

## 8.3 代码复杂度

- 函数圈复杂度不超过10
- 组件代码不超过200行
- 文件代码不超过500行
