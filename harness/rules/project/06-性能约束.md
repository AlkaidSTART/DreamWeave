# 项目约束 - 性能约束

## 6.1 响应时间目标

| 场景 | 目标响应时间 | 监控指标 |
|------|-------------|----------|
| 页面加载 | < 2s | TTI |
| 提示词润色 | < 1s | API响应时间 |
| 任务创建 | < 500ms | API响应时间 |
| 单张图片生成 | < 15s | 任务处理时间 |
| 图片上传 | < 500ms | API响应时间 |

## 6.2 并发处理目标

| 指标 | 目标值 | 测试场景 |
|------|--------|----------|
| 并发任务数 | 10+ | 同时提交10个生成任务 |
| 队列吞吐量 | 100任务/分钟 | 持续提交任务 |
| SSE连接数 | 50 | 同时监听50个任务进度 |

## 6.3 资源使用目标

| 资源 | 目标值 | 告警阈值 |
|------|--------|----------|
| CPU使用率 | < 70% | 80% |
| 内存使用率 | < 80% | 90% |
| Redis内存 | < 500MB | 800MB |
