# 项目约束 - 安全约束

## 5.1 输入验证

| 验证项 | 约束 |
|--------|------|
| 提示词长度 | 1-2000字符 |
| 图片格式 | jpg/jpeg/png/gif/webp |
| 图片大小 | ≤10MB |
| 文件命名 | 禁止特殊字符，使用UUID |

## 5.2 API安全

- **限流**: 每个IP每分钟最多10次生成请求
- **认证**: 生产环境必须添加API密钥认证
- **CORS**: 限制允许的Origin
- **请求体限制**: 最大1MB

## 5.3 文件安全

- **文件类型检查**: 校验文件magic number，不依赖扩展名
- **路径遍历防护**: 禁止`..`等路径遍历字符
- **文件存储隔离**: 每个任务使用独立目录
- **定时清理**: 超过7天的文件自动清理

## 5.4 数据安全

- **API密钥**: 环境变量存储，禁止日志输出
- **传输加密**: 生产环境必须使用HTTPS
- **敏感信息**: 禁止存储用户输入的原始提示词（可选）
