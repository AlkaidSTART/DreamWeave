# 项目约束 - 文档约束

## 9.1 代码文档

- 所有公共函数/方法必须有JSDoc注释
- 复杂逻辑必须有内联注释
- API接口必须有OpenAPI文档

## 9.2 项目文档

| 文档 | 路径 | 更新频率 |
|------|------|----------|
| PRD | `docs/PRD.md` | 需求变更时 |
| TDD | `docs/TDD.md` | 测试用例变更时 |
| 技术选型 | `docs/技术选型文档.md` | 技术栈变更时 |
| 项目约束 | `harness/rules/` | 约束变更时 |
