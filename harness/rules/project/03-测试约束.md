# 项目约束 - 测试约束

## 3.1 测试框架

- **单元测试**: 使用Vitest，Jest兼容模式
- **集成测试**: 使用Vitest + Supertest
- **E2E测试**: 使用Playwright

## 3.2 测试覆盖率

| 层级 | 覆盖率目标 | 强制要求 |
|------|------------|----------|
| 单元测试 | 80%+ | 是 |
| 集成测试 | 核心流程覆盖 | 是 |
| E2E测试 | 关键用户路径 | 是 |

## 3.3 测试隔离

- 每个测试用例必须独立，互不影响
- 使用`beforeEach/afterEach`清理测试数据
- 测试数据库使用ioredis-mock模拟
- 外部服务使用MSW拦截

## 3.4 测试执行

- **开发阶段**: 每次提交前必须通过单元测试
- **CI/CD阶段**: 必须通过所有测试才能部署
- **测试命令**: 统一使用`npm test`系列命令
