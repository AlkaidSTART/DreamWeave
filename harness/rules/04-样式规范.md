# 编码规范 - 样式规范

## Tailwind CSS 4 规范

- **CSS-first配置**: 在`app/globals.css`中配置主题
- **自定义工具类**: 使用`@theme`定义自定义工具类
- **层叠顺序**: 使用`layer(base/components/utilities)`控制层叠

```css
@import "tailwindcss";

@theme {
  --color-primary: #8B5CF6;
  --color-primary-dark: #7C3AED;
  --color-primary-light: #A78BFA;
  
  --font-sans: 'Geist', system-ui, sans-serif;
  
  --shadow-glow: 0 0 20px rgba(139, 92, 246, 0.3);
  
  --animate-pulse-slow: pulse-slow 3s ease-in-out infinite;
}

@keyframes pulse-slow {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}
```

## 样式组合规范

- **工具类组合**: 使用Tailwind工具类直接在组件中定义样式
- **复杂样式**: 复杂样式使用CSS模块或`@layer components`
- **响应式设计**: 使用`sm:`/`md:`/`lg:`/`xl:`前缀

```tsx
function Card({ children }) {
  return (
    <div className="bg-white/10 backdrop-blur-lg rounded-xl p-6 shadow-glow border border-white/20">
      {children}
    </div>
  );
}
```
