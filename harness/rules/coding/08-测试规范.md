# 编码规范 - 测试规范

## 测试文件命名

- **单元测试**: `*.test.ts`
- **集成测试**: `*.test.ts`（放在`tests/integration`目录）
- **E2E测试**: `*.spec.ts`（放在`e2e`目录）

## 测试编写规范

- **AAA模式**: Arrange-Act-Assert模式
- **测试名称**: 描述性名称，说明测试目的和预期结果
- **隔离性**: 每个测试独立，使用`beforeEach/afterEach`清理

```typescript
describe('PromptService', () => {
  let service: PromptService;
  
  beforeEach(() => {
    service = new PromptService(mockApiClient);
  });
  
  it('should return refined prompt for valid input', async () => {
    const result = await service.refine('cat');
    expect(result).toBe('A cute cat');
  });
  
  it('should return original prompt on API failure', async () => {
    mockApiClient.post.mockRejectedValue(new Error('API error'));
    const result = await service.refine('cat');
    expect(result).toBe('cat');
  });
});
```
