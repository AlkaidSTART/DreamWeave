## 4.3 依赖注入约束

**约束**:
- 所有外部依赖必须通过构造函数注入
- 禁止使用全局单例模式
- 测试时必须能够替换依赖为Mock

**示例**:
```typescript
class ImageService {
  constructor(
    private apiClient: ApiClient,
    private storage: StorageService
  ) {}
  
  async generate(prompt: string): Promise<string[]> {
    const results = await this.apiClient.generate(prompt);
    return await this.storage.save(results);
  }
}
```
