# Harness 流程概览

## 完整流程闭环

```
User Input → AGENTS.md → 01-任务分析 → 02-Agent选择 → agents/* → rules/* → 03-代码实现 → 04-测试验证 → 05-代码提交 → 06-CICD → 部署完成
```

## 流程阶段

| 阶段 | 文件 | 核心动作 |
|------|------|----------|
| 00 | [流程概览](00-流程概览.md) | 了解完整流程闭环 |
| 01 | [任务分析](01-任务分析.md) | 识别任务类型、类别、优先级 |
| 02 | [Agent选择](02-Agent选择.md) | 根据任务类型选取对应Agent |
| 03 | [代码实现](03-代码实现.md) | 编写代码、遵循规范、TDD开发 |
| 04 | [测试验证](04-测试验证.md) | Lint → TypeCheck → Build → Test → 接口验证 |
| 05 | [代码提交](05-代码提交.md) | 自动完善提交信息、推送到dev分支 |
| 06 | [CICD流程](06-CICD流程.md) | GitHub Actions自动合并到main分支 |

## 流程触发

| 触发方式 | 流程入口 |
|----------|----------|
| 新需求 | AGENTS.md → 01-任务分析 → 02-Agent选择 → ... |
| Bug修复 | AGENTS.md → 01-任务分析 → 02-Agent选择 → ... |
| 代码优化 | AGENTS.md → 01-任务分析 → 02-Agent选择 → ... |

## 核心工具链

| 工具 | 用途 | 命令 |
|------|------|------|
| ESLint | 代码检查 | `npm run lint` |
| TypeScript | 类型检查 | `npm run typecheck` |
| Next.js | 构建验证 | `npm run build` |
| Vitest | 单元测试 | `npm run test:unit` |
| Playwright | E2E测试 | `npm run test:e2e` |
| GitHub Actions | CI/CD | 自动触发 |

## 分支策略

```
main ──←── develop ──←── feature/* / bugfix/* / hotfix/*
```

| 分支 | 用途 | 操作 |
|------|------|------|
| main | 生产环境 | 自动合并 |
| develop | 开发环境 | 功能分支合并目标 |
| feature/* | 功能开发 | 从develop创建 |
| bugfix/* | Bug修复 | 从develop创建 |
| hotfix/* | 紧急修复 | 从main创建 |
