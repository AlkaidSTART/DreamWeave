# Harness 流程概览

## 流程总览

```
需求分析 → 设计评审 → 代码实现 → 测试验证 → 代码审查 → 部署发布 → 监控运维
```

## 流程阶段

| 阶段 | 文件 | 职责 |
|------|------|------|
| 01 | [需求分析](01-需求分析.md) | 理解需求、评估优先级 |
| 02 | [设计评审](02-设计评审.md) | 架构设计、API设计 |
| 03 | [代码实现](03-代码实现.md) | 编写代码、遵循规范 |
| 04 | [测试验证](04-测试验证.md) | 编写测试、验证功能 |
| 05 | [代码审查](05-代码审查.md) | 审查代码、确保质量 |
| 06 | [部署发布](06-部署发布.md) | 部署应用、验证功能 |
| 07 | [监控运维](07-监控运维.md) | 监控系统、处理问题 |

## Agent角色分配

| 阶段 | 主要Agent | 辅助Agent |
|------|-----------|-----------|
| 需求分析 | 开发Agent | - |
| 设计评审 | 架构Agent | 开发Agent |
| 代码实现 | 开发Agent | - |
| 测试验证 | 测试Agent | 开发Agent |
| 代码审查 | 审查Agent | - |
| 部署发布 | 部署Agent | 运维Agent |
| 监控运维 | 运维Agent | - |

## 触发条件

| 流程类型 | 触发条件 |
|----------|----------|
| 功能开发 | 新需求、功能增强 |
| Bug修复 | 代码缺陷、异常行为 |
| 技术债务 | 代码重构、优化 |

## 工具链

| 工具 | 用途 |
|------|------|
