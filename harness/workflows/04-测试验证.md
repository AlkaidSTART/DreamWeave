# 阶段 04: 测试验证

## 目标

编写测试用例，验证功能正确性，确保代码质量。

## 触发条件

- 代码实现完成
- 需要验证功能
- 需要确保代码质量

## 操作步骤

### 步骤 1: 单元测试

#### 测试范围

| 测试项 | 说明 |
|--------|------|
| 函数测试 | 测试独立函数 |
| 模块测试 | 测试模块功能 |
| 边界测试 | 测试边界条件 |
| 异常测试 | 测试异常情况 |

#### 测试命令

```bash
# 运行单元测试
npm run test:unit

# 生成覆盖率报告
npm run test:coverage
```

#### 测试标准

- 测试覆盖率≥80%
- 所有测试通过
- 无TypeScript错误

### 步骤 2: 集成测试

#### 测试范围

| 测试项 | 说明 |
|--------|------|
| API测试 | 测试API接口 |
| 服务测试 | 测试服务间协作 |
| 队列测试 | 测试队列功能 |

#### 测试命令

```bash
npm run test:integration
```

#### 测试标准

- 核心流程覆盖
- 所有测试通过

### 步骤 3: E2E测试

#### 测试范围

| 测试项 | 说明 |
|--------|------|
| 用户流程 | 测试关键用户路径 |
| 界面交互 | 测试界面交互 |
| 兼容性 | 测试浏览器兼容性 |

#### 测试命令

```bash
npm run test:e2e
```

#### 测试标准

- 关键路径覆盖
- 所有测试通过

### 步骤 4: 类型检查和Lint

```bash
# 类型检查
npm run typecheck

# Lint检查
npm run lint
```

## 输出产物

| 产物 | 说明 |
|------|------|
| 单元测试 | 函数/模块级测试 |
| 集成测试 | API/服务级测试 |
| E2E测试 | 端到端测试 |
| 测试报告 | 覆盖率报告 |
