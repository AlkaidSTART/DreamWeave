# 阶段 02: Agent选择

## 目标

根据任务类型，选取合适的Agent角色，进入对应的开发流程。

## 触发条件

- 任务分析完成
- 需要确定开发角色

## 操作步骤

### 步骤 1: 根据任务类型选择Agent

#### 前端开发任务

| Agent | 职责 | 适用场景 |
|-------|------|----------|
| **前端UI Agent** | 页面开发、组件实现、交互设计 | 实现页面、组件、样式、用户交互 |

#### 后端开发任务

| Agent | 职责 | 适用场景 |
|-------|------|----------|
| **Node.js后端Agent** | API开发、服务实现、队列处理 | 实现API、服务层、队列任务、外部集成 |

#### 通用开发任务

| Agent | 职责 | 适用场景 |
|-------|------|----------|
| **开发Agent** | 实现功能、编写代码 | 通用功能开发、Bug修复、跨模块开发 |

#### 质量保障任务

| Agent | 职责 | 适用场景 |
|-------|------|----------|
| **测试Agent** | 编写测试、验证功能 | 单元测试、集成测试、E2E测试 |
| **审查Agent** | 代码审查、质量保证 | 代码审查、PR审查 |

#### 运维任务

| Agent | 职责 | 适用场景 |
|-------|------|----------|
| **部署Agent** | 部署应用、运维管理 | 部署、配置管理、回滚 |
| **运维Agent** | 监控系统、处理问题 | 监控、告警、性能优化 |

### 步骤 2: 查看Agent定义

选择Agent后，查看对应的Agent定义文件：

```bash
# 前端开发
cat harness/agents/frontend-agent.md

# 后端开发
cat harness/agents/backend-agent.md

# 通用开发
cat harness/agents/dev-agent.md

# 测试验证
cat harness/agents/test-agent.md

# 代码审查
cat harness/agents/review-agent.md
```

### 步骤 3: 查阅约束文档

根据Agent定义，查阅相关约束文档：

| Agent | 必备约束文档 |
|-------|----------|
| 前端UI Agent | TypeScript规范、组件规范、样式规范 |
| Node.js后端Agent | TypeScript规范、API规范、服务层规范、队列层规范 |
| 开发Agent | 所有编码规范、架构约束 |
| 测试Agent | 测试规范、测试约束 |

## 输出产物

| 产物 | 说明 |
|------|------|
| Agent选择结果 | 确定使用的Agent角色 |
| 约束文档列表 | 需要遵循的约束文档 |
